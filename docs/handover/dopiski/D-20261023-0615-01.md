## Decyzja F7 (kontrola liczby)

Bez wspólnej migawki RR `count(*)` przed COPY i `assertCsvMatchesDbCount` (równość) dają fałszywe ERROR przy wstawkach/retencji w trakcie (`integration_runs`, `notifications`, …).

**Zasada:** `n0 = count` przed COPY, `n1 = count` po COPY; poprawnie, gdy `min(n0,n1) ≤ csv ≤ max(n0,n1)`; poza przedziałem → ERROR z `csv`, `n0`, `n1`. Funkcja: `assertCsvInCountWindow`.

**Świadomie:** kopia **nie jest migawką spójną między tabelami** (różne chwile COPY). Retencja i kompletność w obrębie jednej tabeli — przedziałem; spójność międzytabelowa nie jest gwarantowana (jak przy limicie wall-clock + `continue_run`).
