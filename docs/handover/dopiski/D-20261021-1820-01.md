## 1. SG-17 — `loaded_confirmed` widzi załadunek z GPS
`loaded_confirmed` → true także gdy `actual_load_at is not null` (albo było `MILESTONE_LOADED`). Zamknąć otwarte `PORT_NO_LOADED` z `actual_load_at`.

## 2. SG-23 — emtrack: cisza naczepy
Gdy ostatnia pozycja ma źródło `EMTRACK_WEB`: brak `SILENT_VEHICLE` / `NO_POSITION` / powiadomień przy progu `SILENT_MIN`.
Wyjątek: cisza ≥ `SILENT_MIN_EMTRACK` (720 min, `l3_ops`) przy statusie w drodze → jedno ryzyko LOW dla HHL, bez decyzji, bez e-maila i SMS; zamyka się przy nowej pozycji.
RIO i inne źródła bez zmian. Sprzątanie: SILENT + decyzja `NO_POSITION` + `decision-overdue` + powiadomienia przeczytane (jak B8).

## 3. SG-03 — `ETA_BREACH` po dostawie
Brak alarmu ETA (i zamknięcie), gdy `actual_delivery_at is not null` albo `load_status_rank(status) >= load_status_rank('AT_SITE')`, także `CANCELLED`.

## 4. KR-01 — numery zleceń po zmianie daty
`detect_missing_order_numbers` zamyka otwarte `ORDERNO:*`, gdy termin > `p_now + p_lead_h` albo status poza `PLANNED`…`READY` (CARRIER: od `AT_LOADING` wzwyż).
