2. Baza: start i koniec Podglądu funkcją; `HHL_ADMIN` i `mfa_satisfied`, inaczej `42501`. `HHL_OPS` nie zaczyna Podglądu ani „Działaj jako”.
3. Testy `e9-role`, jednostkowe ról i brama `42501`.
4. Odbiór SELECT: starty w `audit_log` tylko od `HHL_ADMIN`.
