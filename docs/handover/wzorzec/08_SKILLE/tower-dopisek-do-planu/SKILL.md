# tower-dopisek-do-planu

Format:
```
DOPISZ
ID: X-NN · P0|P1|P2
Opis: co i dlaczego — PEŁNY warunek, bez skrótów
Przykład liczbowy: wejście → oczekiwany wynik
Kryterium odbioru: testy, które muszą przejść
```
Zasady:
- reguła warunkowa zawsze w całości („gdy jest okno → od końca okna; gdy okna
  nie ma → od końca dnia") — **skrót zepsuł działający kod (I-25)**
- decyzja właściciela: data, brzmienie, co zastępuje
- paczka kilku pozycji → wykonawca potwierdza listą ID
- niczego nie kasujesz; zmiana = nowy wpis ze wskazaniem, co zastępuje
