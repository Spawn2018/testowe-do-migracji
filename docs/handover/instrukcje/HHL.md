# Instrukcja HHL — Watch Tower (1 strona)

**Dla:** koordynatorzy H&H Logistics · **Język:** PL · **Data:** 02.10.2026

## Start dnia
1. Zaloguj się (e-mail + hasło; administrator: 2FA).
2. **Kokpit** — ETA, ryzyka otwarte, status floty. Klik w ryzyko/status → decyzja lub transport.
3. **Harmonogram** — import XLSX z KSH („Importuj”); sprawdź różnice przed zapisem.

## Transport
4. Przypisz rejs (Polferries / Stena). W szufladzie: awizacja, numer HHL, link dla kierowcy (SMS lub skopiuj).
5. **Mapa** — pozycja GPS i prom (AIS). Brak danych = komunikat „brak źródła”, nie cisza.
6. **Decyzje** — każde otwarte zdarzenie z katalogu; wybór opcji + opcjonalny komentarz; eskalacja według reguł.

## Dokumenty i pieniądze
7. **Dokumenty** — CMR/POD, zezwolenia, polisy OCP (zatwierdzenie HHL). Paczka ZIP za tydzień.
8. **Finanse / Faktury** — stawki SYMBOL, SEFS, waluta EUR/PLN przy wystawieniu.
9. **Opcje** — użytkownicy, bramka SMS, progi, macierz powiadomień, historia zmian, stan systemu.

## Zasady
- Nie wysyłaj danych osobnych poza system. SMS do kierowców tylko po R-2 (RODO).
- Ceny z cennika nie trafiają do frontu — tylko wynik wyliczenia.
- Awaria: sprawdź „Stan systemu” (kopie, integracje, bramka SMS).
