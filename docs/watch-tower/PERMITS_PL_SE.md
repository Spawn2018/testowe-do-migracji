# Limity i zezwolenia PL / SE — research SoT (2026-09-23)

Tylko dane potwierdzone źródłami urzędowymi. Nie interpretujemy „czy Twoje SG-01 przejdzie” bez wymiarów **zestawu** (pojazd+ładunek) i nacisków osi.

---

## POLSKA

### Kiedy pojazd jest nienormatywny
Definicja (Prawo o ruchu drogowym + GDDKiA): naciski osi **lub** wymiary **lub** rzeczywista masa całkowita większe od dopuszczalnych.

### Limity „normatywne” (powyżej = potrzeba zezwolenia odpowiedniej kategorii)
Źródło: Rozporządzenie MI w sprawie warunków technicznych… **Dz.U. 2024 poz. 502 t.j.** (§ 2):

| Parametr | Limit (typowy transport towarowy) |
|---|---|
| Szerokość | **2,55 m** (2,60 m dla nadwozia chłodniczego z izolacją ≥45 mm / kontener klimatyzowany) |
| Wysokość | **4,00 m** |
| Długość — pojazd silnikowy (nie autobus) | **12,00 m** |
| Długość — pojazd członowy (ciągnik+naczepa) | **16,50 m** |
| Długość — samochód + przyczepa | **18,75 m** |

Masa i naciski osi: zależą od konfiguracji osi / homologacji / znaków — **przekroczenie = nienormatywny** (nie ma jednej liczby „zawsze 40 t” niezależnej od zestawu).

### Kategorie zezwoleń (I–V)
Źródło: tabela GDDKiA „Tabela kategorii zezwoleń i opłat” (PDF na gov.pl/gddkia) + ustawa PoRD; procedura: rozporządzenie MI **Dz.U. 2024 poz. 126 t.j.**

| Kat. | Kluczowe limity zestawu (skrót z tabeli GDDKiA) | Drogi | Organ (skrót) |
|---|---|---|---|
| **I** | L, H, naciski, masa ≤ dopuszczalne; **szerokość ≤ 3,5 m** | publiczne **bez** S i A | starosta |
| **II** | naciski+masa ≤ dop.; **szer. ≤ 3,2 m**; **dł. ≤ 15 m** (poj. poj.) / **≤ 23 m** (zespół); **wys. ≤ 4,3 m** | publiczne | starosta / UCS |
| **III** | masa+naciski ≤ dop.; **szer. ≤ 3,4 m**; dł. ≤15 / ≤23 / **≤30 m** (skrętne osie); **wys. ≤ 4,3 m** | **krajowe** | GDDKiA / UCS |
| **IV** | szer. ≤**3,4 m** (jednojezdniowa) / ≤**4,0 m** (A i S dwujezdniowa); dł. jak III; wys. ≤4,3 m; **masa ≤ 60 t**; naciski ≤ dop. | publiczne | GDDKiA |
| **V** | wymiary lub masa **powyżej** I–IV **lub** naciski powyżej dopuszczalnych | **wyznaczona trasa** w zezwoleniu | GDDKiA (lub prezydent miasta — warunki w tabeli) |

Od **1.07.2026** wnioski kat. GDDKiA → Oddziały GDDKiA (nie Centrala) — komunikat GDDKiA.

### Pilotowanie (PL)
Źródło: Rozporządzenie MI **Dz.U. 2023 poz. 2487** (tekst PDF dziennikustaw.gov.pl):

- **1 pojazd pilotujący**, gdy przekroczony choć jeden próg: długość **> 23,00 m** LUB szerokość **> 3,20 m** LUB wysokość **> 4,50 m** LUB RMC **> 60 t**
- **2 pojazdy** (przód+tył), gdy: długość **> 30,00 m** LUB szerokość **> 3,60 m** LUB wysokość **> 4,70 m** LUB RMC **> 80 t** (oraz kolumna)

## SZWECJA

### Limity bazowe (publiczne drogi, nie enskild väg)
Źródło: **trafikförordningen (1998:1276)** 4 kap. + Transportstyrelsen:

| Parametr | Limit |
|---|---|
| Szerokość (z ładunkiem) | **2,60 m** (autobus 2,55 m) — 4 kap. 15 § |
| Długość (z ładunkiem) | **24,0 m** generalnie; **25,25 m** EMS przy spełnieniu warunków 4 kap. 17 § |
| Wysokość | **Brak ogólnego limitu ustawowego typu 4,5 m** — obowiązuje skrajnia drogi / znak C17 (wolna wysokość). Trzeba sprawdzać trasę. |
| Masa | Zależna od **klasy nośności drogi BK1–BK4** i rozstawu osi (tabele Transportstyrelsen). Przekroczenie dopuszczalnej masy drogi/pojazdu → zawsze dispens. |

### Ładunek niepodzielny (odelbar last) — bez indywidualnej dispensy (tylko przepisy TSFS)
Źródło: Transportstyrelsen „Odelbar last…” + **TSFS 2023:36** / **TSFS 2023:37**:

| Przypadek | Bez dispensy od väghållare? | Warunek |
|---|---|---|
| Tylko szerokość, **≤ 3,50 m** | Tak — TSFS 2023:36 (warunki oznakowania/varningsbil itd.) | ładunek **odelbar**; przy ≤3,10 m lżejsze warunki; niektóre ulice ≤3,10 m (bilaga 1) |
| Szerokość **> 3,50 m** | **Zawsze dispens** | |
| Szerokość > **2,60 m** + jednocześnie długość lub masa ponad normę | **Zawsze dispens** | |
| Tylko długość, **≤ 30,0 m** | Tak — TSFS 2023:37 | ładunek odelbar + warunki przepisu |
| Długość **> 30,0 m** | **Zawsze dispens** | |
| Długość > **24,0 m** + jednocześnie szerokość lub masa ponad normę | **Zawsze dispens** | |
| Jakakolwiek nadwaga | **Zawsze dispens** | |
| Pojazd konstrukcyjnie za szeroki/długi/ciężki bez ładunku | **Zawsze dispens** | |

### Kto wydaje dispens (SE)
- Trasa w **jednej** gminie → gmina
- Trasa w **więcej niż jednej** gminie → Trafikverket (region startu)

## Implikacja dla Stegra (orientacyjnie — wymaga wymiarów ZESTAWU)
Elementy typu L≈18,21 m przy standardowej naczepie → zestaw zwykle **> 16,50 m (PL)** i często **> 24 m z ładunkiem (SE)** → typowo zezwolenie PL (często kat. zależna od L/W/H/masy zestawu) + po stronie SE ścieżka TSFS 2023:37 i/lub dispens jeśli łączone przekroczenia. **Nie klasyfikujemy automatycznie bez L/W/H/masy/nacisków zestawu.**
