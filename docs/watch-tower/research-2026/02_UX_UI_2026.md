| Principle | Practice for WATCH TOWER |

## 2. Typography (beyond current stack)

VISUAL_BRIEF already rejects Inter/Barlow/Roboto/Poppins and points to a free control-tower stack (IBM Plex family in makieta history). **2026 upgrade options** (pick one direction, don’t mix 4 families):

### Direction A — Keep Plex, tighten craft (recommended P0)
- **IBM Plex Sans** UI + **IBM Plex Mono** for IDs, ETAs, money, VIN, MMSI.
- Optical sizes: 12/13 table, 14 body, 16 section — no 20+ hero.
- Tabular lining figures everywhere for times and PLN/EUR/SEK.

### Direction B — “Instrument” (P1 visual refresh)
- **Geist Sans / Geist Mono** (Vercel) or **Söhne**-like → free proxy **Inter Tight is still Inter — avoid**.
- Better free instrument feel: **JetBrains Mono** + **Source Sans 3** OR **IBM Plex** + **Fragment Mono**.
- Reference: Linear’s use of compact sans + mono for IDs.

### Direction C — Nordic industrial (brand-adjacent Stegra)
- **Switzer / Satoshi** (Fontshare) for UI; mono = **IBM Plex Mono**.
- Risk: trendy startup look — keep radius ≤6 px and cold steel surfaces to avoid “SaaS landing”.

**Anti-pattern:** variable display fonts, gradient text on KPI, mixed 3+ families.

## 5. Anti-AI-slop checklist (product craft)

Fail review if any appear:

1. Chatbot as primary navigation.  
2. “AI Insight” card with no inputs/assumptions.  
3. Autopilot that updates ETA/status without run log.  
4. Stock 3D truck heroes / purple gradients.  
5. Confetti on POD upload.  
6. Blurred prices instead of RLS hide.  
7. Fake precision (`ETA 14:37:12` from ±90 min model).  
8. Copied competitor accuracy %.

Pass pattern (NDara / KlarOps-like): **proposal · evidence · confidence · owner · approve/override/escalate**.

## 8. Visual direction recommendations (concrete)

### Keep
- Ink `#080F15` / steel surfaces / amber `#E5A544` / coral crit / teal OK / ferry blue.  
- Corridor spine.  
- Severity gut.  
- Hide-not-blur prices.

### Change / intensify (P1)
1. **Mono everywhere for machine data** (load code, ferry code WAW/NS, permit IDs).  
2. **Queue row anatomy:** `[gut][code][segment chip][ETA band][owner][next action][age]` — one line.  
3. **Evidence drawer strip** for workflow proposals (inputs used).  
4. **Map legend collapse** to 1 icon row; layers as checklist.  
5. **Focus mode** dims non-selected loads to 40% opacity (not blur).  
6. Optional **high-contrast** theme for site cabin (Stegra) — larger type, fewer columns.

### Reference boards to pin (names, not vibes)
- Linear Issues list (density)  
- Bloomberg Terminal watchlist (information hierarchy — don’t copy colors)  
- FlightAware / MarineTraffic map+list (AIS adjacency)  
- Swedish Trafikverket traffic map calm blues (corridor authenticity)  
- Stegra brand photography: industrial cold, not startup pastel — use as mood only

### Color extension (optional, one only)
If amber feels “warning-only”, introduce **electric steel** accent `#7EB6D4` solely for interactive focus rings already partially covered by `--wt-focus`. Do **not** add a second product accent.
